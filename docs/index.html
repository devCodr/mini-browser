Multi-Session Architecture & Partitioning

How MiniBrowser isolates multiple accounts without cookie or session collisions.

The Problem with Traditional Browsers

Standard browsers (Chrome, Safari, Brave, Edge) share the browser cookie jar, LocalStorage, and IndexedDB globally across all open tabs and windows. Opening two tabs for WhatsApp Web or Gmail results in one account overriding the other, forcing users to juggle private/incognito windows or sluggish multiple profile instances that each consume hundreds of megabytes of RAM.

How MiniBrowser Solves It

MiniBrowser strictly sandboxes every account into an independent, persistent disk partition on your local filesystem:

Filesystem Partition LayoutmacOS / Linux / Windows 
$APP_DATA/sessions/
├── whatsapp-personal/    👉 Cookies, IndexedDB, WebCrypto Keys, Cache
├── whatsapp-work/        👉 Completely separate sandbox partition
├── gmail-corporate/      👉 Separate Google authentication tokens
└── facebook-client/      👉 Zero cross-site tracking or shared cache
💡
Native Rust & Tauri v2 Performance MiniBrowser leverages system-native web engines (WebKit on macOS, WebView2 on Windows, WebKitGTK on Linux). The entire app idles at just ~50 MB RAM and the standalone installer is only 4.8 MB.

Tab & Session Organization (4 Reordering Workflows)

Organize dozens of tabs smoothly with multiple intuitive workflows.

MiniBrowser gives you 4 distinct ways to sort and manage tabs based on your preferred workflow:

1

Right-Click Context Menu

Right-click (or Ctrl + click on Mac) any tab to reveal options: Move Left, Move Right, Manage Sessions, or Close Session.

2

Global Shortcuts

Press Cmd + Option + ← or → (Ctrl + Alt + ←/→). Registered natively in the OS menu bar so they trigger even while typing inside websites.

3

Fluid Drag & Drop

Click and hold any tab in the top bar, then drag left or right. Other tabs automatically part in real-time to preview the new layout before releasing.

4

Session Manager (Cmd + M)

Open the management modal to view all sessions vertically. Use 1-click ↑ and ↓ buttons, rename tabs, change badges, or delete.

📜
Horizontal Tabs Wheel & Trackpad Scrolling When managing 10 or more open accounts, the tab bar automatically enables horizontal scrolling. Simply hover over the header and scroll your mouse wheel or perform a two-finger trackpad swipe. Left and right edge gradient masks ensure seamless navigation without abrupt visual cutoffs.

How to Customize a Session

  1. Press Cmd + M (or Ctrl + M) to open the Session Manager.
  2. Click the pencil icon (✏) next to any session.
  3. Enter a custom title (e.g. "WhatsApp Operations") and a concise badge code (e.g. "W2").
  4. Select an accent color (Green, Red, Blue, Purple, Amber, Cyan).
  5. Click Save. The top tab bar and native macOS menu immediately update with your badge!

PIN Security Shield & Auto-Lock

Protect your sensitive chats, confidential inboxes, and workspaces from unauthorized local access.

MiniBrowser includes a built-in cryptographic security layer with a 6-digit SHA-256 PIN shield and full UI blur masking:

⏱️

Inactivity Auto-Lock

Configure an idle timer (1, 5, 15, 30, or 60 minutes) in Settings. When no input is detected, the browser automatically engages the lock overlay.

🚀

Lock on Launch

Require your 6-digit PIN before any web sessions or tab contents are revealed upon launching the application.

👁️

Discreet Minimized Start

Enable "Start Minimized" to let the app start quietly in the background without abruptly flashing windows on your desktop.

⚡

Emergency Instant Lock

Hit Cmd + Option + L (Ctrl + Alt + L) anytime to immediately conceal all webviews behind the glass shield.

🛡️
Factory Default PIN & Setup The default factory PIN is 123456. You can change this to any 6-digit passcode anytime by clicking the Settings gear icon (⚙️) and selecting "Change PIN". The hash is saved locally using SHA-256 with salt.

Installation & Compiling from Source

Build and run MiniBrowser on macOS, Windows, and Linux.

Prerequisites

  • Rust (1.75+): Install via curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  • Node.js (v18+) & pnpm: npm install -g pnpm
  • Platform dependencies (macOS Xcode Command Line Tools, Windows Visual Studio C++ Build Tools, or Linux libwebkit2gtk-4.1-dev).

Development Mode

Terminalbash / zsh 
# 1. Clone the repository
git clone https://github.com/devCodr/mini-browser.git
cd mini-browser

# 2. Install frontend and Tauri CLI dependencies
pnpm install

# 3. Launch hot-reloading development server
pnpm dev

Production Release Build

To compile optimized production binaries, run:

Terminalbash / zsh 
pnpm build

Tauri will output native standalone packages to src-tauri/target/release/bundle/:

  • macOS: Apple Silicon & Universal .dmg and .app (~4.8 MB)
  • Windows: .msi installer and standalone .exe
  • Linux: .deb package and portable .AppImage

Frequently Asked Questions & Troubleshooting

Common scenarios, permission requests, and configuration tips.

🔑 macOS Keychain "WebCrypto Key" Dialog

WhatsApp Web uses the modern W3C WebCrypto API to store end-to-end encryption master keys. WebKit on macOS delegates this storage to your native macOS Keychain. When the prompt appears:

Select "Always Allow" and input your Mac password once. This allows WhatsApp Web to store encryption keys persistently without prompting on every startup.

✉️ Google Sign-In ("Browser not secure")

Standard automated browsers trigger Google's untrusted browser warning. MiniBrowser uses genuine Safari 18 User-Agent signatures and routes directly to Google's official sign-in endpoint:

Type gmail.com into the address bar or click the Gmail preset; it connects seamlessly to accounts.google.com/ServiceLogin without automation flags.

📁 Where is my session data stored?

All cookies, local storage, indexed databases, and credentials are saved locally in:

  • macOS: ~/Library/Application Support/com.larico.minibrowser/sessions/
  • Windows: %APPDATA%\com.larico.minibrowser\sessions\
  • Linux: ~/.config/com.larico.minibrowser/sessions/

There is zero external telemetry or cloud sync. Your data never leaves your computer.

🛡️ What if I forget my PIN?

Because your security PIN is hashed with SHA-256 locally on your computer, you can reset it by navigating to your user data folder and opening settings.json. You can reset "lock_enabled": false or remove the hashed PIN to regain access.

🔊 Multiple audio playback across sessions

Each session partition acts as an autonomous browser instance. You can stream media, receive audio notifications from WhatsApp Web, and run webinars in separate tabs without audio muting each other.

🧹 How do I completely clear a session?

Press Cmd + M to open the Session Manager and click the trash can icon (🗑). MiniBrowser will close the active webview and purge that session's bookmarks and partition data.
